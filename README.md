# Eventra Updated

This repository contains the clean, neat and colorful Eventra design-system package uploaded from the September 27, 2026 update.

## Included

- Tailwind design tokens
- Global CSS
- Reusable Button, Card, Badge, Input and Table components
- Responsive DashboardLayout
- Login and Signup UI
- Dashboard home UI

## Important

The LoginPage and SignupPage currently contain **UI/demo submission delays**, not real authentication. They are intended to be connected to Eventra's production authentication and multi-tenant authorization backend.

This repository is a design-system/UI handoff, not yet a complete standalone deployable Eventra application.
